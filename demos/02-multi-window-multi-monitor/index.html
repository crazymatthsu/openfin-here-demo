Launch inside Here Core / OpenFin

Start Deephaven (see shared/deephaven/README.md), keep this dev server running, then from demos/02-multi-window-multi-monitor:

npm run launch        # = npx openfin --launch --config http://localhost:5174/manifest.fin.json

Or, if the Here Core / OpenFin RVM is installed, open fins://localhost:5174/manifest.fin.json.

Two platform windows open: trading-desk (blotter, desk controller, monitor) on your primary screen and market-data (Deephaven panels) on your second screen, or tiled side by side on a single screen.

Browser mode (no OpenFin runtime, reduced fidelity)

  • Order Blotter
  • Desk Controller — screen and window management needs Here Core; the sync status works everywhere
  • Interop Monitor
  • Deephaven Bridge (needs Deephaven on localhost:10000)

Pages served by this dev server

  • /manifest.fin.json — platform manifest with two windows and per-window screen hints
  • /platform/provider.html — provider: window placement override + Interop Broker
  • /blotter/, /desk/, /monitor/, /bridge/ — the panels
  • /preload/deephaven-bridge.js — preload script injected into the Deephaven view
