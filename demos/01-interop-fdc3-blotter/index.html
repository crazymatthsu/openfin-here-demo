Launch inside Here Core / OpenFin (the real demo)

Start Deephaven (see shared/deephaven/README.md), keep this dev server running, then from demos/01-interop-fdc3-blotter:

npm run launch        # = npx openfin --launch --config http://localhost:5173/manifest.fin.json

Or, if the Here Core / OpenFin RVM is installed, open fins://localhost:5173/manifest.fin.json.

Browser mode (no OpenFin runtime, reduced fidelity)

Open each panel in its own tab. They share context through a BroadcastChannel-based FDC3 shim.

  • Order Blotter — type a symbol and press Enter
  • Interop Monitor — shows every context received
  • Deephaven Bridge — writes the symbol into Deephaven (needs Deephaven on localhost:10000; add ?server=http://host:port to change)
  • Deephaven quotes_filtered, trades_filtered, positions_filtered, price_chart, Deephaven IDE

Pages served by this dev server

  • /manifest.fin.json — platform manifest (runtime, provider, layout snapshot)
  • /platform/provider.html — platform provider, creates the Interop Broker
  • /blotter/, /monitor/, /bridge/ — the panels
  • /preload/deephaven-bridge.js — preload script injected into the Deephaven view
